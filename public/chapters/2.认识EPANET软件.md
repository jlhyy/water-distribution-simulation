
### 1. 为什么是EPANET？

![[EPANET.png|55]]
这就是我们今天要认识的主角——**EPANET**。

在开始之前，你可能会问：“市面上水力建模软件那么多，为什么偏偏从它开始？”

问得好。这就好比你想学编程，有人建议你直接上手企业级IDE，也有人告诉你先装个Python再说。选择EPANET，不是因为它最强大，而是因为它是**这个行业里最适合“从零开始”的那把手术刀**。

选择 EPANET 作为入门工具，核心原因在于它同时满足了两方面的需求：对于初学者，它由美国环境保护署开发并维护，完全开源且免费，不需要申请许可证或支付费用，下载安装后即可直接使用，这意味着你可以随时开始练习，即使建错了模型也能删除重来，没有任何经济负担；对于有进阶需求的用户，它提供了基于 C 语言的计算引擎（EPANET Toolkit），能够被 Python 等其他编程语言调用，支持批量模拟、自动校核和优化调度等高级功能的开发，不会因为软件功能封闭而限制你的后续成长。

### 2. 把EPANET装到你的电脑上

EPANET的安装极其简单，不需要配置环境变量，不需要装依赖库，下载完双击就能用。

> **下载地址**：  
> 访问美国EPA官网的EPANET页面：[https://www.epa.gov/water-research/epanet](https://www.epa.gov/water-research/epanet)，找到最新版本的下载链接（目前是EPANET 2.2）。

![[10002.png]]

往下滑动界面，我们就能看到软件的安装包了。

![[0fa1ae65ebb24ff79b7f4dc9a5d53a16.png]]

这里有三栏东西，其实都是安装EPANET的。
第一个**Self-Extracting Installation Program for EPANET 2.2 (EXE)**
是EPANET 2.2版本的安装包。下载打开安装包后，点击安装即可。

![[10001 1.png|553]]

第二个**Non-Installing Software for EPANET 2.2 (ZIP)（推荐）**

也是EPANET 2.2版本的安装包。不过是免安装的，解压zip文件后，就可以直接打开软件使用了。

![[10003 1.png]]

第三个**Self-Extracting Installation Program for EPANET 2.00.12 (EXE) (exe)** 

这个是EPANET 2.0版本的安装包。

跟2.2版本的相比，2.0版本功能会少一点。

第一个exe文件没法选择指定路径安装。

**第二个免安装的可以自己选择解压的文件路径，而且里面还有案例管网以及用户使用手册。**

**个人更推荐直接下载第二个免安装的zip文件。**
点击链接安装有时候会比较慢，使用科学上网的方式会快一些。也可以在这里==点击下载==：

打开EPANET2.2的界面

![[10004 1.png]]
